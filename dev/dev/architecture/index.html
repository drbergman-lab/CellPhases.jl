One call, start to finish

cellPhases(positions, values, ids; dt, band) then PhaseWaves(p; r):

  1. cellPhases checks lengths, builds the filter (bandpassFilter, always with fs = 1/dt), and derives trim (_filtermemory) and minlength if not given.
  2. Positions become SVector{D,Float64}; _byagent gathers each ID's (frames, rows); _runs splits at gaps.
  3. Each long-enough run is transformed (_transform), mean-subtracted, filtfilt-ed and hilbert-ed. Interior frames receive phase and amplitude, written back at [frame][row]; the run becomes a Track.
  4. PhaseWaves maps each (frame, row) to the agent's row in the next frame through the tracks, builds a KDTree per frame, fits a plane per agent (_planefit) and pushes one entry per fit.

PhaseCoherence and OrderParameter draw all surrogate phase sets first (_phasesets) and accumulate observed and surrogate sums in one pass over neighbour pairs; _nullstats turns the surrogate columns into null, band and p-value.

Invariants

  • Per-frame fields stay aligned with the input. phase[t][i] is the agent in row i of input frame t; nothing reorders rows. The PhysiCell extension sorts rows by ID once, before the array method.
  • One time unit, the user's. Band, trim, minlength and dt share whatever unit the input uses; no unit is assumed. Speeds are position units per that unit. fs is always passed to DSP.
  • Scales have no defaults: band, dr, rmax, radii, r.
  • Sign conventions: φ = 0 at peaks of the band-passed signal; direction is the angle of −∇φ; a wave moving +y reads +90°.
  • Tracks, not IDs, are the unit of a series. Surrogates shift tracks; cycle lengths and z-scores are per track.
  • The null is the time-shift surrogate. Never a per-frame shuffle for bands or p-values.
  • Extensions are thin adapters ending in the array method; no second PhysiCell reader.
  • Plot data holds the decisions; recipes only draw.

Tests

julia --project=. -e 'using Pkg; Pkg.test()'

Each area is its own @testset in test/runtests.jl; the shared geometry FIELD is defined at the top, so a single testset can be pasted into a REPL after those few lines. The PhysiCell test writes its input to a temporary directory with MAT.jl.

Adding to it

A new readout goes in src/readouts.jl (or its own file) with a result struct and a show method, a method for AbstractVector{<:PhaseResult} in src/replicates.jl that defines how it pools, a plot-data function in src/plotdata.jl if it is drawn, and a recipe that draws from that function. A new input form should end in a call to the array method of cellPhases.
