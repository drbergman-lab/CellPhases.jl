API reference

Phases

CellPhases.cellPhases — Function
cellPhases(positions, values, ids; dt, band, order = 3, trim = nothing, minlength = nothing,
           transform = identity, mask = 0.0) -> PhaseResult

Give every tracked agent a phase for its oscillating value, frame by frame.

Inputs are per frame: positions[t] (points as tuples or vectors), values[t] and ids[t], one entry per agent present in frame t. Frames must be equally spaced, dt apart. All times (dt, band, trim, minlength) are in one time unit of your choice.

For each agent, consecutive frames form a run; runs of at least minlength are transformed by transform (identity by default), mean-subtracted, band-passed (zero-phase Butterworth of order, periods band = (pmin, pmax); see bandpassFilter), and Hilbert-transformed. A time trim is dropped from each end of the run, where the filter has not settled.

band = (pmin, pmax) are periods and dt the frame interval, in the same time unit; see bandpassFilter for how they become cutoffs.

  • trim defaults to the filter's memory (frames for its slowest pole to decay to 1/e), rounded up to whole frames.
  • minlength defaults to 2trim + 2pmax: two of the slowest cycles left after trimming. It cannot be set below 2pmax.
  • mask = q sets the phase to NaN in each run's frames whose amplitude is below that run's q-quantile. Off (0) by default; see the manual for when to use it.

Examples

julia> using Random

julia> rng = Xoshiro(1); xy = [(100.0rand(rng), 100.0rand(rng)) for _ in 1:200];

julia> positions, ids = fill(xy, 150), fill(1:200, 150);

julia> v = planeWave(positions; dt = 10, period = 180, speed = 0.5, direction = 90,
                     rng = Xoshiro(2));

julia> p = cellPhases(positions, v, ids; dt = 10, band = (100, 300));

julia> length(p.tracks), p.trim
(200, 180.0)
source
cellPhases(sequence::PhysiCellSequence; value, cell_types = nothing, include_dead = false,
           dims = 2, kwargs...) -> PhaseResult

Phases of a cell variable across the snapshots of one PhysiCell output folder. Requires using PhysiCellOutput.

  • value: the cell variable, e.g. :notch or any custom data label.
  • cell_types: cell type names to keep (a name or a collection of names); nothing keeps all. A cell outside the selection in some snapshots (it changed type) has a gap there, which splits its trace.
  • include_dead: keep cells PhysiCell marks as dead.
  • dims: use position_1, position_2 (and position_3 with dims = 3).

dt is the snapshot interval, read from the snapshot times; snapshots must lie on one time grid (a missing snapshot is a gap). The remaining keywords (band, order, trim, minlength, transform, mask) are those of the array method.

Examples

using PhysiCellOutput, CellPhases
sequence = PhysiCellSequence("output")
p = cellPhases(sequence; value = :notch, cell_types = "rgc", band = (100, 300))

CellPhases.PhaseResult — Type
PhaseResult{D,I}

The phase of every tracked agent in every frame, returned by cellPhases.

All per-frame fields are aligned with the input: phase[t][i] belongs to the agent in row i of frame t.

  • phase: Hilbert phase in (−π, π]; 0 is the peak of the band-passed signal. NaN where the agent has no phase (track too short, inside the trimmed ends, or masked).
  • amplitude: Hilbert amplitude of the band-passed, transformed signal; NaN where unavailable.
  • positions, ids, values: the input, with positions as SVector{D,Float64} and values as given (before the transform).
  • tracks: the Tracks that received a phase.
  • Settings: dt, band, order, trim, minlength (all times in the unit of dt), transform, mask.
source
CellPhases.Track — Type
Track{I}

One run of consecutive frames of one agent that received a phase.

  • id::I: the agent's ID.
  • frames::UnitRange{Int}: the frames with a phase (the run with trim cut from each end).
  • rows::Vector{Int}: the agent's row in each of those frames.

An agent that is missing from a frame, or changes into a cell type that was not selected, has its trace split there; each piece long enough becomes its own Track.

CellPhases.bandpassFilter — Function
bandpassFilter(band; dt, order = 3)

The band-pass filter cellPhases applies: a Butterworth filter of the given order.

  • dt: the frame interval.
  • band = (pmin, pmax): the shortest and longest periods to keep, in the same time unit as dt. Any unit works; it only has to be the same for both.

The conversion is explicit: the cutoff frequencies are 1/pmax and 1/pmin cycles per time unit and the sampling rate is fs = 1/dt samples per time unit, and fs is always passed to DSP.digitalfilter. Normalised frequencies are never used. With dt = 10 and band = (100, 300): fs = 0.1, cutoffs 1/300 and 1/100 cycles per time unit.

The cutoffs are the half-power points of one pass (amplitude gain 1/√2). cellPhases applies the filter forward and backward (filtfilt), which squares the gain, so as applied the cutoffs are half-amplitude points.

pmin must exceed 2dt: the shortest period a frame interval can resolve is two frames.

Examples

julia> using DSP

julia> f = bandpassFilter((100, 300); dt = 10);

julia> periods = [100, 170, 300];   # same unit as dt

julia> H = freqresp(f, 2π .* (1 ./ periods) .* 10);   # radians per sample = 2π · (1/period) · dt

julia> round.(abs2.(H); digits = 3)   # amplitude gain as applied (forward and backward)
3-element Vector{Float64}:
 0.5
 1.0
 0.5

CellPhases.timeShift — Function
timeShift(p::PhaseResult; rng = Random.default_rng()) -> PhaseResult

A time-shift surrogate of p: each track's phase and amplitude series is circularly shifted by an independent random number of frames. Positions, IDs and values are unchanged.

Every agent keeps its own rhythm and amplitude, while phases at the same moment in neighbouring agents become unrelated. PhaseCoherence and OrderParameter use it for their null bands and p-values; any readout can be run on it directly.

Examples

julia> using Random

julia> rng = Xoshiro(1); xy = [(50.0rand(rng), 50.0rand(rng)) for _ in 1:50];

julia> positions, ids = fill(xy, 120), fill(1:50, 120);

julia> v = planeWave(positions; dt = 10, period = 180, speed = 0.5, direction = 0,
                     rng = Xoshiro(2));

julia> p = cellPhases(positions, v, ids; dt = 10, band = (100, 300));

julia> s = timeShift(p; rng = Xoshiro(2));

julia> sort(filter(!isnan, s.phase[60])) == sort(filter(!isnan, p.phase[60]))
false

CellPhases.PhaseCoherence — Type
PhaseCoherence

The result of PhaseCoherence(p::PhaseResult). Per distance bin:

  • centers: bin centres (position units); bin k holds pairs at distance within dr/2 of centers[k].
  • coherence: mean cos(φᵢ − φⱼ) over same-frame pairs.
  • null: the same, averaged over time-shift surrogates; excess = coherence − null.
  • nulllow, nullhigh: 2.5% and 97.5% quantiles of the surrogate values.
  • pvalue: one-sided, (1 + #surrogates ≥ coherence) / (1 + nsurrogates).
  • counts: pairs behind each value; surrogates: one column per surrogate.

CellPhases.OrderParameter — Type
OrderParameter

The result of OrderParameter(p::PhaseResult). Per radius:

  • radii; R: the mean over agent-frames of the local order parameter |mean e^{iφ}| over the agents within that radius (centre included).
  • null, nulllow, nullhigh, pvalue, surrogates: as in PhaseCoherence, from time-shift surrogates; excess = R − null.
  • counts: agent-frames behind each value.

CellPhases.PhaseWaves — Type
PhaseWaves

The result of PhaseWaves(p::PhaseResult; r). One entry per agent-frame with enough neighbours for a fit:

  • frame, id, position: where the fit was made.
  • gradient: the fitted local phase gradient ∇φ (radians per position unit).
  • r2: the fit's R²; low values mean no single plane wave explains the neighbours.
  • direction: the direction of travel, the angle of −∇φ in radians (0 = +x, π/2 = +y).
  • omega: the agent's own phase advance to the next frame, radians per time unit of dt; NaN when it has no phase in the next frame.
  • speed: omega / |∇φ|, position units per time unit, relative to the agents; NaN where omega is missing or not positive.
  • r, minneighbours: the settings.

Report cleanShare next to any summary of directions or speeds.

Replicates{T}

A readout run on each of several PhaseResults (replicate simulations), returned by the lowercase readout functions: phaseCoherence(runs; …), orderParameter, phaseWaves, cycleLengths, phaseValueCheck.

Plot data

CellPhases.roseData — Function
roseData(w::PhaseWaves; bin = 20, minr2 = 0.5, rings = (5, 10)) -> NamedTuple

Everything needed to draw the directions of local phase waves as a rose diagram, from the fits with r2 ≥ minr2. Directions are compass angles in degrees, 0 = right (+x), 90 = up (+y).

Wedges are bin degrees wide; a wedge's length is √share (share in percent), so its area is proportional to the number of fits. Fields:

  • wedges: one closed polygon per wedge, a vector of (x, y) tuples starting at the origin.
  • lo, share: each wedge's start angle (degrees) and its share of fits (%).
  • speed: median speed per wedge (position units per time unit; NaN for an empty wedge).
  • rings: (radius, label) reference circles at the shares in rings; labelangle: the centre of the shortest wedge, where ring labels least overlap the wedges.
  • rlim: radius of the outermost ring or wedge.
  • meandirection (degrees), resultant (mean resultant length R), arrow: the tip of an arrow from the origin of length R·rlim in the mean direction.
  • compass: (x, y, label, halign, valign) for the labels right, up, left, down.
  • up, down: shares (%) within ±45° of up and of down; clean: cleanShare (%); n: number of fits drawn.

Examples

julia> using Random

julia> rng = Xoshiro(1); xy = [(150.0rand(rng), 150.0rand(rng)) for _ in 1:300];

julia> positions, ids = fill(xy, 150), fill(1:300, 150);

julia> v = planeWave(positions; dt = 10, period = 180, speed = 0.5, direction = 90,
                     rng = Xoshiro(2));

julia> w = PhaseWaves(cellPhases(positions, v, ids; dt = 10, band = (100, 300)); r = 30);

julia> rose = roseData(w);

julia> rose.lo[argmax(rose.share)], round(rose.meandirection; digits = -1), rose.up > 95
(80.0, 90.0, true)

CellPhases.planeWave — Function
planeWave(positions; dt, period, speed, direction, noise = 0.3, baseline = 1.0,
          rng = Random.default_rng())

Values of a plane wave exp(baseline + cos(ωt − k·x) + noise·ε) at the given per-frame positions (2D): period period, travelling at speed position units per time unit in direction degrees (0 = +x, 90 = +y). Frame t is at time (t − 1)·dt; ε is standard normal noise.

The phase cellPhases returns is ωt − k·x, so φ = 0 at the wave's peaks.

                     direction = 0, noise = 0);

julia> round.(log.(only.(v)); digits = 3)
2-element Vector{Float64}:
 2.0
 1.0

CellPhases.pulseTrain — Function
pulseTrain(ids; dt, period, width = period / 10, jitter = 0.05, baseline = 0.1, noise = 0.2,
           rng = Random.default_rng())

Pulse-like values for the agents in per-frame ids: each agent fires a Gaussian pulse of standard deviation width once per cycle, on top of baseline, with multiplicative log-normal noise of SD noise. Each agent's period is period·(1 + jitter·ε) and its first pulse is at a random time, so agents are not in step.

A pulse train is broadband: most of its power lies in harmonics of the period, which is what makes it a real test of the band-pass filter.

Examples

julia> using Random

julia> v = pulseTrain([[1], [1], [1]]; dt = 10, period = 170, rng = Xoshiro(1));

julia> length(v), all(>(0), only.(v))
(3, true)

CellPhases.oscillatorField — Function
oscillatorField(positions, ids; dt, period, correlationlength = 0.0, phasesd = π,
                diffusion = 0.0, noise = 0.3, baseline = 1.0, rng = Random.default_rng())

Oscillators sharing one period whose phase offsets are spatially correlated: exp(baseline + cos(ωt + θᵢ + ψᵢ(t)) + noise·ε).

  • θᵢ is set from the agent's first position. With correlationlength = 0 it is uniform and independent between agents (no coherence at any distance). Otherwise it is a Gaussian random field with standard deviation phasesd and covariance exp(−d²/2ℓ²), ℓ = correlationlength, so the expected phase coherence at distance d is exp(−phasesd²(1 − exp(−d²/2ℓ²))).
  • ψᵢ(t) is a random walk with variance diffusion rad² per time unit: phase noise that slowly breaks the alignment.

Examples

julia> using Random

julia> rng = Xoshiro(1); xy = [(50.0rand(rng), 50.0rand(rng)) for _ in 1:20];

julia> positions, ids = fill(xy, 4), fill(1:20, 4);

julia> v = oscillatorField(positions, ids; dt = 10, period = 180,
                           correlationlength = 20.0, phasesd = 1.0, rng = Xoshiro(2));

julia> length(v[4])
20

Module

CellPhases — Module
CellPhases

Per-agent phase analysis of oscillating values in agent-based model output: band-pass each tracked agent's trace, take its Hilbert phase, and measure how the phases relate in space (coherence with distance, local order parameter, local phase waves).

Entry point: cellPhases. Readouts, each constructed from a PhaseResult: CycleLengths, PhaseValueCheck, PhaseCoherence, OrderParameter, PhaseWaves; for replicate runs, the lowercase functions (phaseCoherence …) return per-replicate and pooled results.
