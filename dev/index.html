CellPhases.jl

Give every tracked agent in an agent-based simulation a phase for an oscillating value, and measure how those phases relate in space.

Tierbrief

Pass per-frame positions, values and IDs with the frame interval and the band of periods to keep; cellPhases returns a phase per agent per frame. The readouts take that result.

Tierfull

The motivating case is a Notch–Delta model of the developing cortex: every radial glial cell cycles its Notch-pathway signals every ~170 minutes, and the questions are how far neighbours are in step and whether phase waves travel through the tissue. A pooled correlation answers neither well, because opposite local waves cancel when pooled. Following each cell's own phase keeps the local structure.

The pipeline per agent: optionally transform the trace (a log, say), band-pass it to the rhythm of interest, and take the angle of its analytic signal (Hilbert transform). The readouts then compare phases across agents: coherence with distance, a local order parameter, and local phase-gradient waves with their direction and speed. Each is compared with a null from time-shift surrogates.

using CellPhases, Random

# toy data: 400 slowly moving agents carrying a wave of period 180 that travels +y at
# 0.5 position units per time unit; frames 10 time units apart
include(joinpath(pkgdir(CellPhases), "test", "agent_field.jl"))   # toy agents
field = agentField(; n = 400, L = 300.0, nframes = 200, step = 0.5, rng = Xoshiro(1))
v = planeWave(field.positions; dt = 10, period = 180, speed = 0.5, direction = 90,
              rng = Xoshiro(2))

p = cellPhases(field.positions, v, field.ids; dt = 10, band = (100, 300))
PhaseResult: 200 frames, dt = 10.0, 2D
  tracks: 400 from 400 agents
  agent-frames with a phase: 65600 of 80000
  band 100.0–300.0, Butterworth order 3, trim 180.0, minlength 960.0

Reading the result

p.phase[t][i] is the phase of the agent in row i of frame t, in (−π, π], with 0 at the peaks of the band-passed signal; NaN where the agent has none. The readouts summarise it:

CycleLengths(p)
CycleLengths: 3212 cycles from 400 agents, median 180.2
PhaseCoherence(p; dr = 10, rmax = 60, frames = 1:4:200, rng = Xoshiro(3))
PhaseCoherence: 7 distance bins to 60.0, 19 time-shift surrogates
  excess coherence: [0.97, 0.83, 0.52, 0.15, -0.17, -0.37, -0.35]
w = PhaseWaves(p; r = 30, frames = 1:4:200)
rose = roseData(w)
(direction = rose.meandirection, speed = rose.speed[argmax(rose.share)],
 clean_percent = rose.clean)
(direction = 90.03716504463719, speed = 0.4985097480922867, clean_percent = 100.0)
